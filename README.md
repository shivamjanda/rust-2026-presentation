## 🔀 How We Work

- Every task starts as an **Issue** with labels and an assignee.
- Work happens on a branch named `feature/<task>` or `bugfix/<task>`, never directly on `main`.
- Changes reach `main` only through a **Pull Request** reviewed by a teammate, which closes its issue with `Closes #N`.
- Team decisions are recorded in **Discussions**.
